# Page Screenshots

Full-app visual tour — a screenshot of every user-facing page rendered with
realistic data. Generated by `e2e/all-pages-screenshots.spec.ts`.

Regenerate with:

```bash
npm run screenshots:pages
```

The spec seeds a dummy account into `localStorage` (auth token + a week of
practice history + SRS review queue + telemetry) and mocks every `/api/*`
endpoint with representative payloads, so no real backend, Azure key, or
microphone is required. Captured at 1440px wide in light mode.
